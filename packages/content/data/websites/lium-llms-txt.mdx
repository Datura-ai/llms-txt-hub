# Lium

> Lium is a GPU rental marketplace. Independent providers list their machines, and renters pick a GPU, pay by the hour and get a pod with SSH access in the browser, from the `lium` CLI, from the Python SDK or through the REST API.

## Key Focus Areas

- Renting GPU pods from the web app, CLI, SDK or API
- Headless sign-up and rental for AI agents
- Public price feed and nodes feed
- Guides for providers who list GPUs

## About llms.txt Implementation

The Lium docs publish an `llms.txt` index of every page, an `llms-full.txt` with the full text, and a Markdown version of each page for agents.
